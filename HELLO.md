This is the biRISC-V project - a 32-bit dual issue RISC-V CPU core.

## About This Project

biRISC-V is a superscalar RISC-V processor implementation featuring:
- Dual-issue in-order pipeline
- RV32IMZicsr support
- Branch prediction
- Linux boot capability

For more information, please see the [README.md](README.md).
